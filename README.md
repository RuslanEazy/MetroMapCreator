# Метро Редактор (Android, Material 3)

Приложение для рисования схем метро: станции, линии, пересадки, экспорт в PNG.

## Сборка без ПК (GitHub Actions)
1. Создай репозиторий на GitHub и загрузи в него все файлы проекта (включая папку `.github`).
2. Вкладка **Actions** → **Build APK** → **Run workflow** (или просто сделай push в `main`).
3. Когда сборка закончится, открой запуск и скачай артефакт **MetroMapMaker-debug-apk** — внутри `app-debug.apk`.

## Управление
- **Станция** — тап по пустому месту ставит станцию и соединяет её с предыдущей на активной линии. Тап по существующей станции начинает цепочку с неё (повторный тап — прервать).
- **Связь** — тап по двум станциям подряд соединяет их активной линией.
- **Двигать** — перетаскивание станции; тап по станции открывает переименование/удаление. Пустое место тянется как карта.
- **Ластик** — тап по станции удаляет её, тап по перегону удаляет перегон.
- Два пальца — масштаб и панорама. Тап по уже активной линии — переименовать / сменить цвет / удалить.
- Меню ⋮: переименовать схему, новая, открыть/сохранить JSON, экспорт PNG в `Pictures/MetroMaps`, привязка к сетке, автосоединение.
- Состояние автосохраняется.
